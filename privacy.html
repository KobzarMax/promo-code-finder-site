Privacy policy

Last updated: 2 November 2026

In short

Promo Code Finder does not collect, send or share your data. Everything the extension needs stays in your browser.

What the extension stores, and where

  • Your promo codes and settings you enter on the options page, in chrome.storage.local on your device.
  • History of which codes saved money on which shop, in chrome.storage.local, so the best codes are tried first. You can clear it on the options page.
  • Field choices if you point at a coupon field yourself: a short CSS selector per shop domain, in chrome.storage.local.
  • A temporary run state in the page’s sessionStorage while codes are being tested, so a shop that reloads the page can be resumed. It is removed when the run ends or the tab closes.

What the extension does not do

  • It does not send your codes, the pages you visit, URLs, basket contents or totals to us or to anyone else.
  • It does not use analytics, advertising or tracking.
  • It does not sell or share data, and it does not use data for creditworthiness or lending decisions.
  • It does not run any code downloaded from a server.

When the extension reads a page

The extension runs in shop pages so it can find the discount code field and the order total. It reads this only on your device. Testing codes starts only after you click “Try codes”.

Permissions

The extension asks for the storage permission only, to keep the data listed above on your device. Its content script runs on HTTPS pages so it can work on any shop’s checkout.

Changes

If a future version adds a feature that contacts a server (for example, downloading a list of licensed offers or cashback), this policy will be updated first and the change will be disclosed in the extension and in the store listing before you install it.
