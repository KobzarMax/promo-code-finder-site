Find the promo code that saves you the most

A browser extension for shoppers in the UK and Europe. At checkout, one click tests your saved promo codes one by one and shows which code gives the biggest discount.

Status: in development, personal beta. Not yet listed in the Chrome Web Store.

How it works

  1. You save your codes. Add them on the options page, one line per shop: shop.co.uk: CODE1, CODE2.
  2. You open a checkout page. The extension looks for the discount code field. If it cannot find it, you can point at the field yourself.
  3. You click “Try codes”. Nothing runs before this click. The extension enters each code, reads the new total, and removes the code again if the shop allows only one.
  4. You see the result. The best code is applied and shown with the exact amount it saves. If no code helps, your basket is left unchanged.

Our rules

  • Only after your click. No background testing, no hidden links, no hidden cookies.
  • Only the coupon field. It never presses Pay or Continue, never removes basket items and never submits a form that holds more than the coupon field.
  • Same behaviour for everyone. No special modes for reviewers or testers and no remotely switched behaviour. All logic ships inside the extension package.
  • No guessing and no scraping. The extension does not try random codes and does not scrape coupon sites. Codes come from you.
  • Your data stays with you. Codes, pages, URLs and totals never leave your browser. See the privacy policy.

Planned: licensed offers and cashback

We plan to add codes from licensed affiliate networks and, later, click-activated cashback. If this happens, it will follow these rules: only after your click, only with a real benefit to you (a working code or visible cashback), never replacing another publisher’s attribution, and with clear disclosure in the extension, on this site and in the store listing before you install.
